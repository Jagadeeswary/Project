1. Credit Card Approval System using Machine Learning

A browser-based application that predicts credit card approval using a TensorFlow.js feedforward neural network.

Type: Binary Classification (Approved / Not Eligible)
Tech Stack: JavaScript, TensorFlow.js, HTML, MySQL
Highlights:
Real-time, in-browser ML inference — no server required
Full user flow: signup/login → personal & work details → ML-based eligibility scoring → bank recommendations
MySQL backend with 10 relational tables (users, applications, activity logs, etc.)
2. Electric Vehicle Population Analysis

An interactive Power BI dashboard analyzing 150,000+ U.S. EV registration records.

Tech Stack: SQL, Power BI, DAX
Highlights:
Tracked EV adoption growth from under 5K (2015) to 37K (2023)
Found Tesla holds 46% market share (Model Y & Model 3 leading)
Surfaced that only 42% of vehicles are confirmed CAFV-eligible
